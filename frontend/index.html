Graph-powered airline route optimization

AirRouteX models every airport as a vertex and every flight as an edge, then runs Dijkstra and BFS - built from scratch on top of Java, JDBC, and MySQL - to find the shortest-distance, cheapest, fastest, or fewest-layover route between any two cities.

How it works

Shortest Distance

Dijkstra's algorithm with each flight's distance in kilometers as the edge weight.

Lowest Price

The same Dijkstra implementation, re-run with ticket price as the edge weight instead.

Shortest Duration

Again the same Dijkstra code, this time minimizing total flight duration in minutes.

Minimum Layovers

Breadth-First Search treats every flight as one unweighted hop to find the fewest-stop route.

Java Servlets + JDBC + MySQL — Graph, HashMap, ArrayList, Queue, and PriorityQueue-based algorithms.
